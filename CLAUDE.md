## Project description

The purpose of this project is to reproduce paper: https://arxiv.org/html/2603.27224v4

You're authorized to install z3 and CodeQL on your local machine if needed and use Python venv to create a virtual environment, with 'uv' to manage it.

You can use OPENAI_API_KEY to get access to OpenAI API. **Only gpt-5.6-luna** is allowed. You can write your own LLM API calls or your own agent or use `codex exec` to use AI.

## User preferences

Always communicate with the user in Chinese.
